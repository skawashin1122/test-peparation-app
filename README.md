# 📝 自分専用！テスト対策4択クイズアプリ

PythonのWebフレームワークである **Streamlit** を使用して作成する、ゲーム感覚の4択暗記学習アプリです。
自分のテスト範囲に合わせたオリジナルのクイズをその場で登録でき、正解率や連続正解コンボ数、ハイスコアを記録しながら、飽きずに勉強を続けることができます。

---

## 🚀 主な機能と仕様

### 1. 動作モードの切り替え（サイドバー）
- **クイズに挑戦モード**: 登録されている問題からランダムで4択クイズが出題されます。
- **問題を追加するモード**: 新しいクイズ（問題文、選択肢4つ、正解の選択肢）を自由に追加・登録できます。

### 2. クイズ挑戦モードの仕様
- **問題のランダム出題**: 登録された問題リストからシャッフルして出題します。
- **ゲーム要素（コンボシステム）**: 
  - 連続で正解すると「〇連続コンボ！」と表示されます。
  - 間違えるとコンボ数は0にリセットされます。
  - 最大コンボ数（ハイスコア）が記録されます。
- **正誤判定**: 選択肢を選んで「回答する」を押すと、正解なら「正解！🎉」、不正解なら「残念、正解は〇〇でした😢」と表示されます。
- **結果発表（リザルト画面）**:
  - 全ての問題を解き終わると、最終スコア（正解数）、正解率（％）、最大コンボ数を表示します。
  - 「もう一度挑戦する」ボタンで問題を再度シャッフルしてリトライできます。

### 3. 問題追加（管理）モードの仕様
- 新しいクイズを以下の入力フォームから登録できます。
  - **問題文**: `st.text_input`
  - **選択肢1〜4**: それぞれ `st.text_input`
  - **正解**: どの選択肢が正解かを `st.selectbox` などで選択
- 「問題を登録する」ボタンを押すと、`quiz_data.json` に即時追加保存されます。

## 💾 データ構造 (quiz_data.json)

データはローカルの `quiz_data.json` に保存されます。初期状態で以下のサンプルデータを持たせます。

    {
        "questions": [
            {
                "id": "1",
                "question": "日本の初代内閣総理大臣は誰？",
                "options": ["板垣退助", "大隈重信", "伊藤博文", "山県有朋"],
                "answer": "伊藤博文"
            },
            {
                "id": "2",
                "question": "光合成を行う植物の細胞小器官はどれ？",
                "options": ["ミトコンドリア", "葉緑体", "液胞", "細胞核"],
                "answer": "葉緑体"
            }
        ]
    }

## 🛠️ セットアップ手順

### 1. 仮想環境の準備と有効化

    python -m venv venv
    # Windowsの場合
    venv\Scripts\activate
    # macOS/Linuxの場合
    source venv/bin/activate

### 2. 必要なライブラリのインストール

    pip install -r requirements.txt

### 3. アプリの起動

    streamlit run app.py
